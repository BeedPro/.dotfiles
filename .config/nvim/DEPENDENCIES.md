# Dependencies

## Required System Dependencies

- Neovim 0.12+
- Git: `git`
- Fuzzy finder: `fzf`
- Search: `rg`
- External opener: `xdg-open`
- Trash support: `trash`
- Rust toolchain: `rustc`, `cargo`

## Optional System Dependencies

- C build tools: `make`
- Java: `java`, `javac`
- JavaScript runtime: `node`
- Python runtime: `python3`
- Typst compiler: `typst`
- Typst formatter: `prettypst`
- LaTeX formatter: `tex-fmt`
- LaTeX language server: `texlab`
- Prolog language server/formatter: `prolog_ls`, SWI-Prolog
- Org language server: `org`
- Browser debugging: `firefox`
- Haskell debugging: `stack`
- Nerd Font
